Funzioni Algebriche

Una funzione si definisce algebrica se nella sua espressione analitica compaiono solo le quattro operazioni aritmetiche fondamentali (addizione, sottrazione, moltiplicazione, divisione) e l'estrazione di radice (o elevamento a potenza con esponente razionale).

Razionali Intere (Polinomiali)

La variabile $x$ non compare a denominatore né sotto radice: $$f(x) = a_n x^n + \dots + a_1 x + a_0$$

  • Lineari ($n=1$): rette $y = mx+q$
  • Quadratiche ($n=2$): parabole $y = ax^2+bx+c$
  • Dominio: sempre tutto $\mathbb{R}$
Razionali Fratte

Rapporto tra due polinomi con $x$ al denominatore: $$f(x) = \frac{P(x)}{Q(x)}$$

  • Condizione: $Q(x) \neq 0$
  • Asintoti verticali: zeri di $Q(x)$
  • Omografica: $y = \frac{ax+b}{cx+d}$ (iperbole equilatera)
Irrazionali

La variabile $x$ compare sotto il segno di radice: $$f(x) = \sqrt[n]{P(x)}$$

  • Indice pari: richiede $P(x) \ge 0$
  • Indice dispari: definita ovunque $P(x) \in \mathbb{R}$
  • Esempio: $f(x) = \sqrt{x+1}$ con $D = [-1, +\infty)$

Funzioni Trascendenti

Si definiscono trascendenti tutte le funzioni reali che non sono algebriche. Comprendono le funzioni esponenziali, logaritmiche, le funzioni goniometriche e le loro inverse.

Esponenziali

La variabile $x$ è ad esponente: $$f(x) = a^x \quad (a > 0, a \neq 1)$$

  • Dominio: $D = \mathbb{R}$
  • Immagine: $(0, +\infty)$ (sempre $> 0$)
  • Passa sempre per il punto $(0, 1)$
  • Crescente se $a>1$, decrescente se $0
Logaritmiche

La funzione inversa dell'esponenziale: $$f(x) = \log_a(x) \quad \text{o} \quad \ln(x)$$

  • Dominio: $D = (0, +\infty)$
  • Immagine: Tutto $\mathbb{R}$
  • Interseca l'asse $x$ nel punto $(1, 0)$
  • Asintoto verticale: retta $x = 0$
Goniometriche

Funzioni circolari periodiche: $$\sin(x), \; \cos(x), \; \tan(x)$$

  • $\sin(x), \cos(x)$: periodo $2\pi$, limitate in $[-1, 1]$
  • $\tan(x)$: periodo $\pi$, asintoti in $\frac{\pi}{2} + k\pi$
  • Inverse: $\arcsin(x), \arccos(x), \arctan(x)$

3. Funzioni a Tratti: Il Valore Assoluto

Una funzione può essere definita tramite leggi analitiche diverse in diversi sottoinsiemi del suo dominio. L'esempio fondamentale è la funzione valore assoluto (modulo):

$$f(x) = |x| = \begin{cases} x & \text{se } x \ge 0 \\ -x & \text{se } x < 0 \end{cases}$$

Il grafico di $|x|$ è una forma a "V", continua su tutto $\mathbb{R}$, simmetrica rispetto all'asse $y$ (funzione pari) con punto angoloso nell'origine $(0,0)$.
